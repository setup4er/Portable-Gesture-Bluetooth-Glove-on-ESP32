## About <a name = "about"></a>

**Gesture Bluetooth Glove** — это носимое устройство на базе ESP32, которое преобразует движения руки в управление курсором компьютера. Перчатка оснащена инерциальным датчиком BNO085 для трекинга ориентации в пространстве и тактильными кнопками для эмуляции левого, правого клика и блокировки курсора.

Устройство подключается к компьютеру по Bluetooth (Classic HID) и распознается как стандартная мышь без установки дополнительных драйверов. Проект разработан в среде PlatformIO с использованием фреймворка ESP-IDF и предназначен для использования в дипломных/курсовых работах, а также в качестве прототипа для систем жестового управления.

**Основные возможности:**
- Управление курсором через наклон кисти (Roll/Pitch)
- Левая и правая кнопки мыши на пальцах
- Блокировка курсора при удержании
- OLED-дисплей для отображения углов и статуса
- Автономное питание от аккумулятора 18650
- Работа с Windows/Linux/macOS без драйверов

## Getting Started <a name = "getting_started"></a>

Эти инструкции помогут вам собрать и запустить проект на вашем компьютере для разработки и тестирования.

### Prerequisites <a name = "prerequisites"></a>

Для работы с проектом вам понадобится:

**Аппаратное обеспечение:**
- Плата ESP32 DevKit (или аналогичная)
- Датчик движения BNO085 (или BNO055)
- OLED дисплей 0.96" I2C (SSD1306)
- Тактовые кнопки 6x6 мм (3-4 шт.)
- Аккумулятор 18650 (2000 мАч)
- Зарядный модуль TP4056 (с защитой)
- Повышающий преобразоватор MT3608
- Провода DuPont и силиконовые провода 26 AWG
- Макетная плата (для прототипирования)

**Программное обеспечение:**
- [Visual Studio Code](https://code.visualstudio.com/)
- [PlatformIO](https://platformio.org/) (расширение для VS Code)
- Драйвер для CH340/CP2102 (для связи ESP32 по USB)
- Git (опционально)

### Installing <a name = "installing"></a>

#### 1. Клонируйте репозиторий
```bash
git clone https://github.com/your-username/gesture-glove.git
cd gesture-glove
```

#### 2. Откройте проект в PlatformIO
Запустите VS Code и откройте папку с проектом. PlatformIO автоматически определит конфигурацию и подгрузит необходимые зависимости.

#### 3. Настройте параметры сборки
Убедитесь, что в файле platformio.ini выбрана правильная плата и фреймворк:
```ini
[env:esp32dev]
platform = espressif32
board = esp32dev
framework = espidf
monitor_speed = 115200
```

#### 4. Соберите и загрузите прошивку
Подключите ESP32 к компьютеру через USB-кабель и выполните сборку:
```bash
pio run --target upload
```
Если прошивка не загружается, зажмите кнопку BOOT на ESP32 во время подключения.

#### 5. Откройте монитор порта для просмотра логов
```bash
pio device monitor
```

## Usage <a name = "usage"></a>

После успешной загрузки прошивки устройство автоматически запускается и становится видимым в списке Bluetooth-устройств как "GlaveSlave".

### Подключение к компьютеру

1. Включите Bluetooth на вашем ПК (Windows, Linux или macOS).
2. Найдите устройство "GlaveSlave" в списке доступных устройств.
3. Нажмите "Подключить" / "Сопрячь".
4. Устройство будет распознано как HID-мышь — никаких драйверов не требуется.

### Управление курсором

| Действие | Как выполняется |
|----------|-----------------|
| Движение курсора | Наклоняйте кисть влево/вправо и вверх/вниз |
| ЛКМ (левый клик) | Нажмите кнопку на указательном пальце |
| ПКМ (правый клик) | Нажмите кнопку на среднем пальце |
| Блокировка курсора | Зажмите кнопку на большом пальце (курсор замирает) |
| Сброс координат | Нажмите кнопку калибровки (устанавливает текущее положение как "ноль") |

### Индикация состояния

Встроенный светодиод на плате ESP32 (GPIO2) информирует о состоянии устройства:

| Режим | Индикация |
|-------|-----------|
| Инициализация | Одно короткое мигание на каждом этапе |
| Подключено к ПК | Постоянное горение |
| Критическая ошибка | Быстрое мигание (100 мс) |

### OLED-дисплей

На OLED-дисплее отображается текущая информация:
```
=== GLOVE ===
Roll:  +12.4°
Pitch: -03.1°
Yaw:   +87.2°
BT:    OK
```

## Hardware <a name = "hardware"></a>

### Схема подключения

| Компонент | Пин ESP32 | Примечание |
|-----------|-----------|------------|
| OLED VCC | 3.3V | Питание 3.3В |
| OLED GND | GND | Земля |
| OLED SDA | GPIO21 | I2C (данные) |
| OLED SCL | GPIO22 | I2C (тактовый) |
| BNO085 VCC | 3.3V | Питание 3.3В |
| BNO085 GND | GND | Земля |
| BNO085 SDA | GPIO21 | Общая шина I2C |
| BNO085 SCL | GPIO22 | Общая шина I2C |
| Кнопка ЛКМ | GPIO19 | Подтяжка к GND |
| Кнопка ПКМ | GPIO18 | Подтяжка к GND |
| Кнопка блокировки | GPIO5 | Подтяжка к GND |
| Кнопка сброса | GPIO23 | Подтяжка к GND |
| LED (индикация) | GPIO2 | Активный HIGH |

### Питание

Устройство питается от аккумулятора 18650 через цепочку:
```
18650 (3.7-4.2В) -> TP4056 -> MT3608 (5В) -> ESP32 (5V)
```

**Компоненты питания:**
- Аккумулятор 18650 (2000 мАч)
- TP4056 USB-C с защитой
- MT3608 повышающий преобразователь (настройка на 5.0В)
- Выключатель для отключения питания

### Сборка

Рекомендуется следующее размещение компонентов на перчатке:

| Компонент | Место размещения |
|-----------|------------------|
| Аккумулятор + TP4056 + MT3608 | Предплечье (тыльная сторона) |
| ESP32 + OLED | Запястье (внешняя сторона) |
| BNO085 | Тыльная сторона ладони |
| Кнопка ЛКМ | Указательный палец (бок) |
| Кнопка ПКМ | Средний палец (бок) |
| Кнопка блокировки | Большой палец (внутри) |
